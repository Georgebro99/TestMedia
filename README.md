# TestMedia (Ripplegram)

Ripplegram is a polished Instagram-style social media prototype built with plain HTML, CSS, and JavaScript.

## Features

- Far-left border-mounted icon sidebar (expands labels on hover)
- Top-left quick create button (plus) with modal post composer
- Post creation requires image file upload (from your device)
- Settings panel for compact feed, activity status visibility, private mode, and animation toggles
- Profile stats with clickable Followers and Following lists
- Story strip, image-first home feed, search grid, profile view, and DMs
- Interactive reactions with heart-burst animation and count bounce feedback
- Persistent browser state via `localStorage`

## Run

Open `index.html` directly in a browser, or run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
