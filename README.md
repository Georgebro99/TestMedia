# TestMedia (Ripple)

Ripple is a realistic social-media prototype built with plain HTML, CSS, and JavaScript.

## Features

- Timeline feed with seeded posts and user-created posts
- Reactions: like, repost, bookmark
- Comment threads per post
- Profile editor (display name, username, bio)
- Trending hashtags sidebar
- Follow suggestions panel
- Local persistence via `localStorage`

## Run

Open `index.html` in any modern browser.

For a quick local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
